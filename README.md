# 🛒 বাজার দর (BazarDor) - Real-time Market Price Tracker

## 📝 Short Description
**BazarDor** is a modern, full-stack web application designed to help users track daily market commodity prices in Bangladesh in real-time. It provides accurate, up-to-date pricing for essential items like rice, pulses, vegetables, meat, fish, and oils, allowing consumers to stay informed about daily market fluctuations.

---

## 🛠️ Technologies Used
* **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
* **Authentication:** [BetterAuth](https://www.better-auth.com/) (Google & GitHub OAuth)
* **Database:** [MongoDB](https://www.mongodb.com/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Deployment:** [Vercel](https://vercel.com/)

---

## ✨ Key Features
1. **Secure OAuth Authentication:** Seamless Sign Up and Sign In experience using Google and GitHub credentials powered by BetterAuth.
2. **Real-time Market Pricing:** Track daily price trends and updates for essential commodities across various categories.
3. **Dynamic Category Filtering:** Easily filter and browse products by specific categories to find daily market rates instantly.
4. **Interactive Product Details:** View comprehensive price details, historical context, and market changes for individual items.
5. **Responsive & Modern UI:** Fully optimized, clean, and user-friendly interface across mobile, tablet, and desktop screens with custom loading skeletons.
